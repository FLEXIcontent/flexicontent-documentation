## Demo sites

The [FLEXIcontent demo site](https://flexidemo.com3elles.com/) by Com3elles shows several complete sites built with FLEXIcontent. Each demo also provides a Joomla Akeeba backup that can be installed locally.

| Demo | Description | Links |
| --- | --- | --- |
| Job board | Offers, geolocation, applications and front-end management. | [View demo](https://flexidemo.com3elles.com/jobboard/) · [Akeeba package](https://flexidemo.com3elles.com/jpa/site-flexi-jobboard.jpa) |
| Real estate | Properties, agents, geolocation, relations and contact form. | [View demo](https://flexidemo.com3elles.com/realestate/) · [Akeeba package](https://flexidemo.com3elles.com/jpa/site-flexi-realestate.jpa) |
| Recipe | Recipe cards, submissions and favourites/wishlists. | [View demo](https://flexidemo.com3elles.com/recipe/) · [Akeeba package](https://flexidemo.com3elles.com/jpa/site-flexi-recipe.jpa) |
| Directory | Multi-category directory, submissions, contacts and moderation. | [View demo](https://flexidemo.com3elles.com/directory/) · [Akeeba package](https://flexidemo.com3elles.com/jpa/site-flexi-directory.jpa) |
| Library | Bookstore with crossed book/author data and ISBN search. | Coming soon |
| Ask for a demo | Propose a site idea to Com3elles. | [Request form](https://flexidemo.com3elles.com/) |

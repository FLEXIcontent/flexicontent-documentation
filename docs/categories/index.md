# Categories

FLEXIcontent categories add their own display, filtering, list and RSS settings on top of the standard Joomla! category fields. Open them from **Components → FLEXIcontent → Categories**.

For the step-by-step administrator procedure, see [Create a category](./create-a-category.md). All options are detailed on the [Options](./options.md) page.

| Section | Options |
| --- | --- |
| Basic | 3 |
| Category display | 91 |
| Search & filter form | 48 |
| Items list | 97 |
| RSS feeds | 33 |
| Email Notifications | 4 |
| Email Notifications | 18 |
| Metadata options | 3 |

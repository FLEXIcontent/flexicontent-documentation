# Content types

A content type defines the fields, authoring rules and display settings available to a category of items. Open a type from **Components → FLEXIcontent → Content Types**.

For the step-by-step administrator procedure, see [Create a content type](./create-a-content-type.md). All options are detailed on the [Options](./options.md) page.

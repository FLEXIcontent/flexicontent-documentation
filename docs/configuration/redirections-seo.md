# Redirections / SEO

Manage redirects and search-engine-friendly URLs generated by FLEXIcontent.

:::info Source
This page is generated from `admin/config.xml` and the official `en-GB.com_flexicontent.ini` / `fr-FR.com_flexicontent.ini` language files of FLEXIcontent 5.x.
:::

### Redirections

| Option | Description | Values | Default |
| --- | --- | --- | --- |
| **Login page**<br />`login_page` | Specify the login page URL. NOTE: The URL is relative to your site! | — | `index.php?option=com_users&view=login` |
| **Unauthorized Page (General non Authorized Viewing)**<br />`unauthorized_page` | Specify the URL / Menu Item ID of the page you wish your visitors / users to land if they don't have enough rights to access the selected content. **NOTE:** If you don't set anything here they be redirected to a 403 page (but always with a message of what happened). **NOTE:** NOTE: The URL is relative to your site! | — | — |

### SEO & SEF URLs

#### URL creation (/segment1/segment2/...)

| Option | Description | Values | Default |
| --- | --- | --- | --- |
| **JGLOBAL_SEF_NOIDS_LABEL**<br />`sef_ids` | JGLOBAL_SEF_NOIDS_DESC | — | `0` |
| **Item links in category listings**<br />`item_links_in_listings` | Category used in the URLs of items shown in category listings. **Main category**: items always link to their URL via their main category, so an item has a single URL even if it is also assigned to secondary categories. **Current category**: items link via the category being viewed, if the item is assigned to it (an item may then be reachable via several URLs, **rel canonical** still points to the main category URL) | — | `0` |
| **Shorter SEF URLs**<br />`add_item_sef_segment` | By default /item/ is appended after the **menu alias** of a CATEGORY MENU ITEM to make an item (article) SEF url, you can select not to use this. **NOTE:** This may be desired if you are installing FLEXIcontent on an Joomla site that already has bookmarked links and links indexed by google and you want to change Joomla category menu items to be FLEXIcontent category menu items or in new sites that you would want to avoid /item/, if possible. ****NOTE: category SEF URLs will get a /category/ if a **category menu item alias** is used in their SEF URLs (e.g. category menu item of their parent category or default menu item is of type category), to avoid this: (a) select your (FLEXIcontent) default menu item to be of type 'item' or 'directory' and (b) set to prefer 'default menu item' instead of 'current' | — | `1` |
| **Default menu item**<br />`default_menu_itemid` | The default menu item for all URLs for which a more appropriate menu item cannot be found, particularly important for SEF URLs, since for SEF URLs /menu_alias/ will appear in them. Also if you want to delete the FLEXIcontent Hidden Menu then create an menu item and set its Itemid here. This menu item can point to some general text article e.g. policy, general info etc | — | — |
| **Default menu item in URLs**<br />`default_menuitem_preference` | 1. Yes, if no other appropriate found: attaches above if no other appropriate more appropriate menu item is not found e.g. a menu item pointing to the category of the currently displayed item. 2. Yes, but prefer active menu item: If no other appropriate menu item is found, it will try to use currently active menu item, and if active does not point to FLEXIcontent it will use the above default. 3. No, (Forces active): If no appropriate menu item is found, the active will be tried, if active does not point to FLEXIcontent, then no menu item id will be appended and component/flexicontent/ will appear in the SEF URL | — | `2` |

#### URLs for Content of language 'ALL'

| Option | Description | Values | Default |
| --- | --- | --- | --- |
| **Use menu items**<br />`route_active_lang` | Content (items, categories, tags) **having language 'ALL'** can have their URL links created to contain menu item aliases of menu items of any other language (if the other language is the current UI language) | — | `1` |

#### Pathway (breadcrumbs module)

| Option | Description | Values | Default |
| --- | --- | --- | --- |
| **Remove default menu item**<br />`default_menuitem_nopathway` | If you set this to yes (RECOMMEND), the default menu item will not be shown in the pathway | — | `1` |
| **Create pathway automatically**<br />`automatic_pathways` | Category and item pathway (displayed by breadcrumbs module) will be created automatically by (a) removing all menu items from the pathway and adding to it the tree path of category titles and the item title. NOTE you can override this setting per category, type and item | — | `0` |

#### Search engine indexing

| Option | Description | Values | Default |
| --- | --- | --- | --- |
| **Rel canonical tag**<br />`add_canonical` | Add a rel canonical meta tag into the source code of your pages, this helps search engines identify a page being viewed via different URLs, and give it better rank, by not indexing it multiple times | — | `1` |
| **Max filters to index**<br />`max_filt_to_index` | Maximum number number of filters in multi-item view URLs to allow indexing by search engines, by adding rel canonical and index + follow 'robots' directive. Note: this includes text-search filter and also multi-value filters will be counted as one filter. When more filters are active then no-index, (but follow) directive will be forced | — | `4` |

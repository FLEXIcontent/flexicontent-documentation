# Fields

Fields are the custom content types of FLEXIcontent. Each type is provided by a plugin and offers its own editing, viewing, SEO and filtering options.

Add a field from **Components → FLEXIcontent → Fields**, then choose its type. The available options depend on the selected type.

:::info Source
These pages are generated from the field plugin XML manifests and the official English and French language files of FLEXIcontent 5.x.
:::

## Guides

- [Create a field](./create-a-field.md) — add a custom field, choose its type, assign it to content types and place it in forms and views.
- [Create a field type](./create-a-field-type.md) — write a new `flexicontent_fields` plugin when existing field types cannot store or process the data.
- [Create a field layout](./field-layouts.md) — customize the frontend value output (`viewlayout`), the form input (`formlayout`) or an image gallery.

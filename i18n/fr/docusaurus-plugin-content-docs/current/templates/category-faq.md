# FAQ — vue catégorie



:::info Source
Cette page est générée depuis `site/templates/faq/category.xml` et les fichiers de langue officiels de FLEXIcontent 5.x.
:::

## Paramètres du modèle

| Option | Description | Type | Valeurs | Défaut |
| --- | --- | --- | --- | --- |
| **Affichage personnalisé du titre**<br />`custom_layout_title` | Ceci sera affiché à l'utilisateur dans la partie publique en tant qu'infobulle du bouton pour changer de mise en page | `text` | — | — |

#### Information de la catégorie

| Option | Description | Type | Valeurs | Défaut |
| --- | --- | --- | --- | --- |
| **Longueur maximum de la description de la catégorie**<br />`descr_cut_text` | Définit le nombre maximum de caractères affichés dans la description d'une catégorie, les descriptions qui dépassent cette valeur seront automatiquement tronquées et '...' seront ajoutés à la suite de la description | `text` | — | — |

#### Sous catégories

| Option | Description | Type | Valeurs | Défaut |
| --- | --- | --- | --- | --- |
| **Longueur maximum de la description de la catégorie**<br />`descr_cut_text_subcat` | Définit le nombre maximum de caractères affichés dans la description d'une catégorie, les descriptions qui dépassent cette valeur seront automatiquement tronquées et '...' seront ajoutés à la suite de la description | `text` | — | — |
| **Colonnes sous-catégories**<br />`tmpl_cols` | Colonnes utilisées pour afficher les sous-catégories | `radio` | `—` = Paramètres globaux<br />`1` = 1 colonne<br />`2` = 2 colonnes<br />`3` = 3 colonnes<br />`4` = 4 colonnes | — |
| **Positionnement des colonnes**<br />`cols_placement` | Sélectionner le positionnement des sous catégories, comme des tuile masonry ou à la suite | `radio` | `—` = Paramètres globaux<br />`0` = En colonne<br />`1` = Comme des tuiles masonry | — |

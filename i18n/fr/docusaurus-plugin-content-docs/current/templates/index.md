# Modèles

FLEXIcontent fournit quatre mises en page (modèles). Chaque modèle propose ses propres paramètres pour la vue contenu et, pour la plupart, pour la vue catégorie.

| Modèle | Description | Options contenu | Options catégorie |
| --- | --- | --- | --- |
| **FAQ** | Regroupe et affiche les contenus par questions/réponses | [99](./item.md) | [5](./category-faq.md) |
| **Grid** | Disposition en colonnes avec mosaïque | [99](./item.md) | [113](./category-grid.md) |
| **Contenus sous forme d’onglets** | Contenus présentés sous forme d’onglets | [99](./item.md) | [8](./category-items-tabbed.md) |
| **Table** | Contenus présentés sous forme de tableau | [99](./item.md) | [30](./category-table.md) |

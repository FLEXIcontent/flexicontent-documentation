# Bouton éditeur — Fichier

FLEXIcontent fournit des plugins pour la recherche, le routage, les notifications, les boutons de l’éditeur et les sitemaps. Activez-les et configurez-les depuis **Extensions → Plugins**. Les 35 plugins de types de champs sont documentés dans la section [Champs](../fields/index.md).

> Affiche un bouton dans l'éditeur de texte pour insérer des liens vers des fichiers Flexicontent. Affiche une fenêtre contextuelle vous permettant de choisir le fichier.

:::info Source
Cette page est générée depuis `plugins/editors-xtd/fcfile/fcfile.xml` et les fichiers de langue officiels de FLEXIcontent 5.x.
:::

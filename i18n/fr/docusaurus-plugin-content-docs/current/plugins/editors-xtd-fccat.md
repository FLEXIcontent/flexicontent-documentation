# Bouton éditeur — Catégorie

FLEXIcontent fournit des plugins pour la recherche, le routage, les notifications, les boutons de l’éditeur et les sitemaps. Activez-les et configurez-les depuis **Extensions → Plugins**. Les 35 plugins de types de champs sont documentés dans la section [Champs](../fields/index.md).

> Affiche un bouton dans l'éditeur de texte pour l'insertion de liens vers les catégories de Flexicontent. Affiche une popup vous permettant de choisir la catégorie.

Cette page est générée depuis `plugins/editors-xtd/fccat/fccat.xml` et les fichiers de langue officiels de FLEXIcontent 5.x.
:::

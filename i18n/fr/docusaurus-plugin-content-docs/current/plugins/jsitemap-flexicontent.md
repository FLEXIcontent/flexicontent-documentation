# Intégration JSitemap

FLEXIcontent fournit des plugins pour la recherche, le routage, les notifications, les boutons de l’éditeur et les sitemaps. Activez-les et configurez-les depuis **Extensions → Plugins**. Les 35 plugins de types de champs sont documentés dans la section [Champs](../fields/index.md).

> Plugin FLEXIcontent pour JSitemap

:::info Source
Cette page est générée depuis `plugins/jsitemap/flexicontent/flexicontent.xml` et les fichiers de langue officiels de FLEXIcontent 5.x.
:::

## Paramètres

| Option | Description | Type | Valeurs | Défaut |
| --- | --- | --- | --- | --- |
| **Portée des catégories JSitemap**<br />`cats_scope` | Description de la portée des catégories JSitemap | `radio` | `0` = Inclure<br />`1` = Exclure | `1` (Exclure) |
| **Catégories JSitemap**<br />`cats` | Jmap plgflexicontent catégories description | `flexicategories` | — | — |

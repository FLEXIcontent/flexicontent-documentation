# Système — Recherche par champs

FLEXIcontent fournit des plugins pour la recherche, le routage, les notifications, les boutons de l’éditeur et les sitemaps. Activez-les et configurez-les depuis **Extensions → Plugins**. Les 35 plugins de types de champs sont documentés dans la section [Champs](../fields/index.md).

> Ajoute une barre de recherche en temps réel dans la vue d'édition de champ FlexiContent (administrateur).

:::info Source
Cette page est générée depuis `plugins/system/flexifieldsearch/flexifieldsearch.xml` et les fichiers de langue officiels de FLEXIcontent 5.x.
:::

## Basique

| Option | Description | Type | Valeurs | Défaut |
| --- | --- | --- | --- | --- |
| **Couleur de Mise en Évidence**<br />`highlight_color` | Couleur d'arrière-plan utilisée pour mettre en surbrillance le terme recherché dans les étiquettes. | `fccolor` | — | `#fff176` |
| **Texte de placeholder**<br />`search_placeholder` | Texte affiché dans le champ de recherche lorsqu'il est vide. | `text` | — | `Chercher dans les options (label, description)...` |

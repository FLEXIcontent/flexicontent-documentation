# Profil utilisateur

Plugin de champ 'Utilisateur Joomla' pour FLEXIcontent

*Plugin : `jprofile` — Profil utilisateur*

:::info Source
Cette page est générée depuis `plugins/flexicontent_fields/jprofile/jprofile.xml` et les fichiers de langue officiels de FLEXIcontent 5.x.
:::

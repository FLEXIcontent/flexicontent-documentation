# Mise à jour Flexi

Canal de mise à jour utilisé pour vérifier les nouvelles versions de FLEXIcontent.

:::info Source
Cette page est générée depuis `admin/config.xml` et les fichiers de langue officiels `en-GB.com_flexicontent.ini` / `fr-FR.com_flexicontent.ini` de FLEXIcontent 5.x.
:::

| Option | Description | Valeurs | Défaut |
| --- | --- | --- | --- |
| **Canal de mise à jour**<br />`update_channel` | Choisissez « Stable » pour les sites de production. Choisissez « Beta » pour recevoir les versions préliminaires à des fins de test. Les versions Beta peuvent contenir des bugs. | — | `stable` |

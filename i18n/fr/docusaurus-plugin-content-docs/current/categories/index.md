# Catégories

Les catégories FLEXIcontent ajoutent leurs propres paramètres d’affichage, de filtrage, de liste et de flux RSS aux champs standard des catégories Joomla!. Ouvrez-les depuis **Composants → FLEXIcontent → Catégories**.

Pour la procédure pas à pas dans l’administration, voir [Créer une catégorie](./create-a-category.md). Toutes les options sont détaillées sur la page [Options](./options.md).

| Section | Options |
| --- | --- |
| Basique | 3 |
| Affichage des catégories | 91 |
| Formulaire de recherche et filtrage | 48 |
| Liste des contenus | 97 |
| Flux RSS | 33 |
| Notifications par Email | 4 |
| Notifications par Email | 18 |
| Options des métadonnées | 3 |

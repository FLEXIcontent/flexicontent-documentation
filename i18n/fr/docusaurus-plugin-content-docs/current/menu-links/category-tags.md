# Contenus étiquetés (vue catégorie)

Seules les options propres à cette vue sont listées ci-dessous. Toutes les autres options sont décrites dans [Vues catégorie — options communes](./category-common.md).

:::info Source
Cette page est générée depuis `site/views/category/tmpl/tags.xml` et les fichiers de langue officiels de FLEXIcontent 5.x.
:::

## Paramètres requis

| Option | Description | Type | Valeurs | Défaut |
| --- | --- | --- | --- | --- |
| **Disposition**<br />`layout` | — | `hidden` | — | `tags` |

:::note
Pour créer un élément de menu de configuration **d’affichage par défaut** (pour toutes les étiquettes sans élément de menu) : 1. Ne sélectionnez aucune étiquette ici 2. Définissez un titre/alias générique, par exemple « tagged » (l’alias apparaîtra dans les URL) et configurez les paramètres de l’élément 3. Ouvrez les paramètres du composant, l’onglet **Listes**, et sélectionnez cet élément comme élément par défaut de la vue catégorie « Contenus étiquetés »
:::

| Option | Description | Type | Valeurs | Défaut |
| --- | --- | --- | --- | --- |
| **- Sélectionner un tag -**<br />`tagid` | Cliquez sur le nom du tag dans le Popup pour le sélectionner | `fctag` | — | `0` |

Cette page est générée depuis `site/views/tasks/tmpl/default.xml` et les fichiers de langue officiels de FLEXIcontent 5.x.

## Paramètres requis

| Option | Description | Type | Valeurs | Défaut |
| --- | --- | --- | --- | --- |
| **Identifiant de tâche précis**<br />`id` | Laissez cette valeur à zéro pour l’élément de menu par défaut du type de tâche | `text` | — | `0` |
| **Type de tâche**<br />`task` | Sélectionner un type de tâche précis à lier | `list` | `—` = Veuillez sélectionner une tâche<br />`download` = (task=download) Téléchargement via un champ de formulaire Fichier<br />`download_file` = (task=download_file) Liens de fichiers via le bouton éditeur « Fichier »<br />`download_files` = (task=download_files) Télécharger plusieurs fichiers sous forme d’archive compressée<br />`weblink` = (task=weblink) Lien web via un champ de formulaire « lien web » | — |
